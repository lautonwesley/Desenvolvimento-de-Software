# 💻 Desenvolvimento de Software

Bem-vindo ao meu repositório de estudos em Desenvolvimento de Software.

Este repositório foi criado para documentar minha jornada de aprendizado na área da tecnologia. Aqui reúno cursos, anotações, exercícios, desafios e projetos desenvolvidos durante minha formação como desenvolvedor.

Meu objetivo é construir uma base sólida em programação e desenvolvimento de software, evoluindo gradualmente dos fundamentos até tecnologias mais avançadas.

A longo prazo, pretendo me especializar no desenvolvimento de soluções baseadas em Blockchain, Web3, DeFi e aplicações descentralizadas.
